# Security policy

This is an experimental project and has no production support commitment yet.

Please do not open a public issue for vulnerabilities that could expose secrets, bypass policy gates, forge evidence, or cause unsafe execution. Use GitHub Private Vulnerability Reporting after the repository is published. Private reporting must be enabled before the first public release.

The project never intentionally executes an MCP server or model as part of scanning. Inputs are treated as untrusted data.
